# 🚀 AI Interview Question Generator

An AI-powered Interview Question Generator built using **React.js**, **Node.js**, **Express.js**, and **Google Gemini AI**.

The application generates role-specific interview questions along with answers and explanations based on the selected difficulty level.

---

## 🌐 Live Demo

### Frontend

https://ai-interview-generator-frontend.onrender.com

### Backend

https://name-ai-interview-generator-backend.onrender.com

---

## ✨ Features

* Generate interview questions using AI
* Select job role
* Choose difficulty level (Easy, Medium, Hard)
* Generate custom number of questions
* AI-generated answers and explanations
* Copy questions to clipboard
* Download questions as PDF
* Responsive and user-friendly interface

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/kar98star/AI-Interview-Generator.git
cd AI-Interview-Generator
```

### Frontend Setup

```bash
cd frontend
npm install
npm run dev
```

### Backend Setup

```bash
cd backend
npm install
npm start
```

---

## 🔑 Environment Variables

Create a `.env` file inside the backend folder:

```env
GEMINI_API_KEY=YOUR_API_KEY
```

Get your Gemini API key from:

https://aistudio.google.com/
